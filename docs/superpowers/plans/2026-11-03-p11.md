# Plano P11 — Pareto e FinOps estendido
1. RED/GREEN `simulate(..., ewma_window=None)`: suaviza a demanda observada só no sinal da política reativa (1 = idêntico ao padrão); benchmarks inalterados.
2. RED/GREEN `peakguard/sweep.py`: grade (utilização, janela EWMA, percentil, min_replicas), máx. 200 combinações, cache JSON por hash (parâmetros + código do simulador), `pareto_front` (custo × ticks fora do SLO).
3. Teste: configuração reativa domina uma proativa; cada política vira ponto; rótulos synthetic/estimated.
4. RED/GREEN `peakguard/finops.py`: requests CPU/mem, bin-packing em nós, ocioso, spot×on-demand (esperança por probabilidade de interrupção), scale-to-zero; tabela de preços hipotética rotulada. Pós-processa a execução, não altera a simulação.
5. CLI `sweep` (explícito, fora do CI) e API `POST /pareto` + `finops` no corpo.
6. Frontend: rota `/api/pareto` e gráfico de dispersão reutilizando painel/legenda do `Chart`.
7. Verificar: suíte + `npm test` + build uma vez; `git diff benchmarks/`; ROADMAP e STATUS.
